# specs/decisions/ — Architecture Decision Records (ADR)

> ADR 记录**已做出的**架构决策及其背景，防止"代码在但原因失传"。

## 状态

**当前登记表为空 —— 尚无任何 ADR。** 这是刻意的：Bootstrap 阶段只建立机制，不制造虚假的架构决策。未来的 ADR 由真正的研究和设计产生（编号从 ADR-0001 开始）。

## 规则

- 文件命名：`ADR-0001-<short-title>.md`；
- 一个决策一份 ADR；决策被推翻时**不删除**旧 ADR，标记 `Superseded by ADR-XXXX`；
- ADR 一经 `Accepted` 即构成约束；修改其内容须产生新 ADR 或在变更机制下显式处理；
- 重大决策（见 AGENT.md §13）必须同时有人工确认记录（谁、何时、依据）。
